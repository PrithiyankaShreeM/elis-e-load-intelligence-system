\# ELIS — E-Load Intelligence System



An AI-based electricity load forecasting and energy intelligence system designed to analyze historical electricity consumption and predict future demand.



\## Project Structure



\- frontend/ — Dashboard and user interface

\- backend/ — API and forecasting logic

\- docs/ — Project documentation

\- data/ — Development datasets



\## Technology Stack



\- React, TypeScript, Vite

\- Python, FastAPI

\- pandas and machine learning models
